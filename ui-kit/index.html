UI 키트

shadcn/ui의 디자인과 인터랙션을 프레임워크 없이 옮겼습니다. 모양은 CSS 블록, 동작은 브라우저 기본 기능(<dialog>, Popover API, <details>)과 순수 JS 모듈입니다. 키보드로 모두 조작할 수 있고, 라이트·다크 모드를 지원합니다.

버튼

종류 6가지(기본, 보조, 외곽선, 고스트, 위험, 링크)와 크기 3가지. hover는 마우스가 있는 기기에서만 반응합니다.

입력·체크박스·스위치

브라우저 기본 입력 요소에 모양만 입혔습니다. 모바일에서는 입력 글자를 16px로 유지해 아이폰에서 화면이 확대되지 않습니다.

모달

브라우저 기본 <dialog>. 열릴 때 살짝 커지며 나타나고(200ms), Esc나 바깥을 누르면 닫히며, 닫힌 뒤 포커스가 버튼으로 돌아갑니다.

프로필 수정

바꾼 내용은 저장을 눌러야 반영됩니다.

드롭다운 메뉴

브라우저 기본 Popover API. 바깥 클릭·Esc로 닫히고, ↑↓ 키로 항목을 이동합니다. 화면 끝에서는 반대쪽으로 열립니다.

툴팁

CSS만으로 동작합니다. 마우스를 올리거나 Tab으로 포커스하면 나타납니다.

장바구니에 담기

아코디언

브라우저 기본 <details>. 같은 name끼리는 하나만 열리고, 지원 브라우저에서는 높이가 부드럽게 늘어납니다.

접근성을 지원하나요?
네. 브라우저 기본 요소를 써서 키보드와 스크린리더가 그대로 동작합니다.
프레임워크가 필요한가요?
아니요. HTML, CSS, 순수 JS 모듈만 씁니다.
다크 모드도 되나요?
네. 시스템 설정을 따르고, 오른쪽 위 버튼으로 직접 바꿀 수도 있습니다.

탭

← → 키로 탭을 옮기고, Tab 키는 선택된 탭에서 바로 내용으로 이동합니다.
